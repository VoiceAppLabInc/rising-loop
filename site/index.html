RISING LOOP Mac / Windows · 無料 · Created by Voice App Lab

ひとつの数字を測り、それを上げる施策を、AI と一緒に回し続ける。 ループの画面と、Claude Code（または Codex）のチャットを、1つのウィンドウにまとめたデスクトップアプリです。

ダウンロード（無料） ▶ 解説動画を見る

HOW IT WORKS

ゴール → ボトルネック → 施策 → 評価。回すたびに、ゴールに近づく。

  1. 施策を始めるには、やりたい施策の「AIに指示」を押して「施策を実行する」を選んで送る。実装が全部 ✅ になったら、同じ「AIに指示」から「完了にして（評価に移す）」
  2. ボタンはぜんぶ、押すと指示文が右のチャットに送られます。カスタマイズ・更新・AIに指示、どれも AI がそれを読んで動きます
  3. ループの期間を決めて（1日1回、週1回、など）、都度「更新」を押して AI に指示。全体のステータスが更新されるので、次の施策に進みます
右のチャットはただの Claude Code（Codex）です。普段どおりに使いましょう
  • （スクショを貼って）「ここをグラフにして」「この説明は短く」
  • 「施策案が弱い。別案で5案だして」
  • 「GA4 の API から数字取って」「Google Drive に保存して」

INSTALL

入れ方

Mac

ターミナル（アプリケーション → ユーティリティ → ターミナル）にこの1行を貼って、Enter。初回も入れ直しも同じです。

curl -fsSL https://rising-loop.web.app/install-app.sh | sh

Apple シリコン・Intel のどちらにも合う版を入れます。

Windows

インストーラーを落として開きます。

Windows 用をダウンロード

「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。

新しい版が出ると、アプリが起動したときにお知らせします。プロジェクトとループは、入れ替えてもそのまま使えます。

GETTING STARTED

使い始め

  1. アプリを開くと、AI を使えるようにする画面が出ます。Claude Code か Codex のどちらか1つを［入れる］→［ログイン］。どちらもアプリの中から公式の手順で入れるので、Node などを先に入れる必要はありません
  2. フォルダを開く… で、このサービス専用のフォルダを選ぶ
  3. チャットで AI と目標（動かしたい数字）を決めると、AI がループの画面を作ります。以後はその画面が入口です
チャットを進める前に、そのフォルダに資料を山ほど入れておきましょう。企画書・仕様書、ソースコード、LP の HTML、GA4・Stripe・管理画面の CSV など、何でも。AI が最初に読んで、目標とボトルネックを考えます。

TIPS

効果を上げるコツ

数字が自動で取れる口を、できるだけ多く AI につなぐこと。GA4・Search Console・Stripe・Shopify・広告管理画面・自社 DB・Google Sheets などの API や MCP をつなぐほど、AI が自分で数字を取りに行けるようになり、更新が速く、評価が正確になります。つなぐ口が無いときは、AI がどの画面で見られるかを聞いて、ブラウザで取りに行きます。

FROM SKILL

スキル版（/rising-loop）を使っていた人へ

アプリを入れて、ループのあるフォルダを開き、「HTMLを最新版にする」を押せば、そのまま使えます。数字・施策・記録は消えず、控えも残ります（［元に戻す］もできます）。
